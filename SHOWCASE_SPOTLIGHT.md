Agent Retry Safety Lab documents a browser-local model of layered attempts, retention and duplicate side-effect exposure. A timeout does not prove that a server action failed or had no effect; retries and jitter do not guarantee exactly-once execution. This spotlight is documentation, not a new software release or availability observation. The interface remains English-only.

Manual showcase pairings: Schema Drift → Retry Safety, CORS Doctor → Retry Safety, and Retry Safety → Webhook Replay.
